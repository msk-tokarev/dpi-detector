# Политика конфиденциальности (Privacy Policy) — DPI Детектор

**Авторы / Издатель:** `by Ivan Tokarev`  
**Дата вступления в силу:** 2026-11-24

1. **Отсутствие сбора данных.** Расширение «DPI Детектор» и Android-приложение «DPI Детектор» **не собирают, не хранят на внешних серверах, не передают третьим лицам и не продают** никакие персональные данные, историю просмотров, куки, пароли или содержимое веб-страниц.
2. **Локальная работа.** Все сетевые диагностические проверки (Whoami, CIDR WhiteList, TCP 16-20 / L4-25, DoH) выполняются исключительно локально с устройства пользователя по его явному нажатию.
3. **Хранение отчётов.** Результаты проверок сохраняются только локально в `chrome.storage.local` (или во внутренней памяти приложения на Android) и могут быть удалены пользователем в любой момент.
4. **Разрешения браузера.**
   - `storage` — хранение пользовательских настроек и истории локальных отчётов;
   - `activeTab` — чтение имени домена текущей открытой вкладки при клике на иконку расширения;
   - `sidePanel` — отображение панели диагностики;
   - `optional_host_permissions` (`http://*/*`, `https://*/*`) — запрашивается только по действию пользователя для отправки диагностических HEAD/POST-запросов к тестируемым доменам;
   - `optional_permissions` (`webRequest`, `nativeMessaging`) — включаются пользователем вручную в настройках для пассивного отслеживания сетевых ошибок и подключения локального Go-компаньона `dpich`.
5. **Открытый исходный код.** Проект основан на открытом ядре [hyperion-cs/dpi-checkers](https://github.com/hyperion-cs/dpi-checkers) (Apache-2.0) и предназначен исключительно для диагностических и исследовательских целей.
